## Built on

- [Tailwind CSS](https://tailwindcss.com) for the utility layer and the token plumbing
- [ApexCharts](https://apexcharts.com) for the charts
- [FullCalendar](https://fullcalendar.io) for the calendar
- [jsvectormap](https://github.com/themustafaomar/jsvectormap) for the world map, with no jQuery
- [Radix](https://www.radix-ui.com) primitives and icons in the React editions
- [Reka UI](https://reka-ui.com) in the Vue edition
- [Outfit](https://fonts.google.com/specimen/Outfit) by Smartsheet, the typeface

These docs are built with [Fumadocs](https://fumadocs.dev) on Next.js.
